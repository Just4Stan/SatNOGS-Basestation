## Notes

- **6.2pF cap**: Exact value not available on Farnell. 6.0pF (dp/3759543) substituted - tune with VNA.
- **56nH inductor**: LQG18HH series (higher Q) used instead of LQG18HN which isn't stocked.
- **VHF matching network**: Values adapted from CC1120 169 MHz reference. Will need VNA tuning.
- **CC1200 packaging**: RHBT = cut tape (good for 2 pcs), RHBR = full reel. Same IC.
- All Farnell dp/ codes work across regions: `https://be.farnell.com/en-BE/.../dp/CODE`
